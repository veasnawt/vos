## Final ABI/security/lifecycle review

Reviewed actual file/syscall/usercopy/process/scope/ext2/block/virtio/scheduler
implementations and the ABI v2 contract, alongside the Stage 1–4 evidence. No
demonstrated new correctness/security defect or architectural redesign was needed.

| Boundary | Final finding and evidence |
|---|---|
| Version/close dispatch | Notes 0/1/2 accepted deliberately; new calls 6–10 gate older ABIs before arguments. File tokens are positive bit-62 serials; all channel tokens are <=0xFFFFFF. V2 close dispatch compares the full argument; v0/v1 routing and channel behavior remain unchanged. |
| Ownership/generations | Registered process pointer plus non-reused PID and exact live global file token. File serials saturate without wrapping; actual last-two-token and exhaustion scenarios remain last in the full file suite. Legacy channel wrap is separately preserved. |
| Rights widths | UINT64_C(15) valid mask before every compact node assignment; widened parent before complement; trusted descriptor validation precedes session reservation. Native and ring-3 matrices cover bits 4–63, defined masks and attenuation, plus token/reference/I/O accounting. Channel creation takes a native uint32_t rights argument; its 32-bit mask is matched to that trusted interface. Ext2 feature words and ELF flags are likewise actually 32 bits. No new narrowing flaw was found. |
| Provisioning/names | Up to two trusted non-root launch grants, never selected by userspace. Lexically validate the entire private path before single-component lookup; reject absolute/empty/NUL/parent paths, final/intermediate symlinks, special targets and root aliases. Exact byte/case comparisons; no Unicode normalization or decoding. No global root or automatic production grant. |
| User mappings/copy commit | Validate the whole requested range and effective USER/WRITE permissions through every page-table level. After waits decode addresses from the live kernel trap frame and validate again. Storage/DMA never receives a user address. Single process thread and IF=0 keep mappings stable during the final copy. |
| Reads and records | <=4096 private bytes; errors discard even a successful private prefix. Zero length still checks ownership/type/READ but ignores pointer/binding; nonzero EOF validates the full destination. Overflow fails before copying. Stat/dirent are exactly 64/272 initialized bytes, with zero reserved/name-tail bytes and no raw inode/device/pointer. |
| Cookies/parser | Cookie is a byte boundary within the held immutable directory, not authority. Mid-record/beyond-size values fail; guessed valid boundaries stay confined. Private advancement; EOF/errors copy nothing. Readdir validates reserved inodes before publication; all twelve malformed overlays remain. |
| Device identity | Volume generation plus block ID, non-reused incarnation, epoch, capacity and reset sequence. Known changes permanently stale the binding, even cached operations. Timeout/interruption reason survives layer mappings; reset initiator sees timeout and subsequent operations stale. |
| Pending owners | An active file session or volume setup pins its owner until synchronous unwind. Process teardown refuses active operations. Pending kill cancels the scope/wakes a blocked thread and is checked before return/copy/publication. Private buffers remain live until unwind. |
| Orphans | Driver-owned DMA plus a scalar ticket survive abandonment; the driver clears its thread owner, and scope end clears stack pointer/TID/guard. Completion/reset retires the reference exactly once. Scheduler and idle service progress without another file call; detach refuses outstanding debt. |
| Finite work | Two tickets including debt, one per PID, <=one submitted request each; 200 ticks plus independent 512 logical / 256 backend / 1024 queue-wait bounds. Polling has a 50,000,000-iteration cap, including IRQ fallback. IF=0 tick stalls do not remove finite polling/work limits. |
| Reclamation/allocation | Eight fixed 5440-byte sessions, eight 32-byte nodes per session; no heap/new frames/threads/stacks. Full quotas, ninth-process rejection, failed grants/setup, repeated kills and exact final frame/thread/reader/node/ticket audits remain. Existing attached baseline is 32 cache + six DMA frames. |
| Panic paths | User argument/corruption/device failures map to errors; internal reference/owner/double-retirement/mapping-change panic guards remain fail-closed.
