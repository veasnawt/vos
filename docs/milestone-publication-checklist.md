# Milestone publication documentation checklist

Apply this review within the authorized publication work and storage budget;
it does not create another milestone or test campaign.

- Review README.md, docs/STATUS.md and docs/ROADMAP.md together.
- Match accepted scope, merge/implementation identities, evidence links,
  limitations and the next authorized work. Distinguish completed N6 components
  from completion of the entire graphical desktop.
- Include representative authentic screenshots and reproducible technical
  evidence; distinguish implementation from design references.
- Preserve historical failures, protected records and accounting. Admit any
  documentation growth through existing storage and source-scope controls.
- Publish or merge only under the owner's applicable authorization.
